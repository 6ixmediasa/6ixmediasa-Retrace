# Retrace V0.2.0

This package continues the working V0.1.6 core and refreshes the desktop UI toward the approved professional dashboard direction.

## What's new in V0.2.0

- professional dark dashboard layout
- refined sidebar navigation
- top action bar
- right-side event details panel
- dashboard summary cards
- cleaner cards, buttons, spacing, and typography
- better monitoring status presentation
- same core recovery / snapshot / timeline engine preserved

## Important note

This environment could update the source package but could not compile the WPF application directly here. The included installer still compiles on Windows during installation the same way previous test builds did.

## Test focus

After installation, please test:

1. app opens normally
2. new dashboard layout renders correctly
3. sidebar navigation works
4. Timeline / Recover / Snapshots still function
5. selecting an event updates the right details panel
6. View and Reverse buttons from the details panel behave correctly
7. monitoring toggle updates status correctly

## Existing functional foundation retained

- file and folder create / modify / rename / delete tracking
- local SQLite timeline
- deleted-file recovery copies
- snapshot creation and restore
- natural-language recovery commands
- local-first design
